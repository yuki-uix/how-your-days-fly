# 第二组：从资料到设计

![总览](overview.jpg)

本组包含 6 份原创日历设计研究。它们把精读资料提炼出的[决策语言](../../.agents/skills/calendar-design-lab/references/design-language.md)应用到具体作品；审美评价仍待用户反馈。

| 样本 | 设计决定 | 实验类型 |
| --- | --- | --- |
| [J1](j1.svg) | 连续周转为横向跨度，月界索引与查读数字保留 | 整体方向 |
| [J2](j2.svg) | 每个民用日期占相同角度 | 受控映射比较 |
| [J3](j3.svg) | 每个月占相同角度，月内日距随月长变化 | 与 J2 共用视觉条件 |
| [J4](j4.svg) | 所选原创光影图像与完整月格共用边缘，字体分工 | 整体方向 |
| [J5](j5.svg) | 七天采用等面积书写区域和共同基线 | 整体方向 |
| [J6](j6.svg) | 比例宽字形作主视觉，完整日期与邻日提供索引 | 整体方向 |

`manifest.json` 保留每份设计卡、完整日期、字体与图像来源、实现/资产哈希。所选图片来自内置 imagegen 的原始文本生成，完整提示词见 `assets/images/paper-light/provenance.json`，未使用外部参考图；来源记录不构成版权或独占性保证。

字体文件未经修改，逐家保留 OFL 许可证；SVG 轮廓用于稳定校样，原字体、文字和布局源仍可用于修改与再生成。

本轮已检查 2027/2028 的日期覆盖与年份重放、等日／等月角度、字体数字宽度、实际字形边界、资产哈希和来源引用；PDF 的 8 页已渲染检查。尚未验证跨用户满意度，J6 的完整逐日系列也尚未制作。

生成方式与依赖见仓库 README。原始 SVG 为生成的校样源；请通过设计卡和脚本修改，或另存版本，避免下次构建覆盖手工修改。
