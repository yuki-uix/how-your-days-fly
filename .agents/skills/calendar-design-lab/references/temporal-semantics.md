# 时间语义：在选择形状前声明要保留的关系

本页将公开研究转成项目的设计决策。来源说明支持时间语义；下方日历规则与实验是本项目的迁移方法，尚不构成用户偏好或审美效果的验证。

## 已阅读的依据

- **[T3]** Aigner、Miksch、Schumann、Tominski，2023，[第 3 章](https://link.springer.com/chapter/10.1007/978-1-4471-7527-8_3)，重点 §3.1.1–3.1.2：时间模型、粒度及时间原语应分别选择；年份、周与月份的关系不能当作单一整齐的层级。
- **[T4]** 同书[第 4 章](https://link.springer.com/chapter/10.1007/978-1-4471-7527-8_4)，重点 §4.1、§4.2.2：从数据、任务、视觉表达共同决定设计；静态表示将时间映射到空间，动态表示可映射到播放时间，是否支持交互是另一项选择。
- **[G]** Huang 等，[ggtime 预印本](https://arxiv.org/html/2510.25656v1)，§§4–7：保留时间元数据与顺序，区分历法与绝对时间；不等长周期可以保持原长度或归一化，但二者表达不同意义。本文引用预印本，不将其作为已核实的同行评审结论。

## 一份方案先写清的决策

这是一张可扩展的决策卡，不是封闭的模板 schema。

| 项目 | 要写清什么 |
| --- | --- |
| 展示范围 | 哪段日期可见，例如 2027 全年；不要与文献中指时点／区间的 scope 混用 |
| 单元与原语 | 一格代表日、小时、事件，还是一个区间；日期标签是否代表整段日子 |
| 历法与基准 | 公历民用日期、时区明确的时刻，或相对某个事件的时间 |
| 映射 | 真实时长、等日单元、事件顺序、周期内归一化进度，哪些距离有意义 |
| 周期与次序 | 保留完整日期，还是取星期／月份等周期属性；起点、方向及周期边界 |
| 空间布局 | 网格、条带、环形、分面或分段；它与时间映射分开记录 |
| 阅读任务 | 优先定位某日、比较跨度、观察周期、书写，或感受整体经过；允许用户补充 |

## 可复用的迁移规则

| 条件 | 本项目采用的决策与检查 | 反例 |
| --- | --- | --- |
| 以民用日期为日历单元 | 用日序号推进、保留原日期；“每天等距”说明是等日单元 | 用秒数除以 86400 推出所有本地日期；未处理夏令时却声称等真实时长 |
| 希望日与日等权 | 统一每天的步长；月份长度自然不同 | 十二个相等扇区同时标成“每天等角度” |
| 希望月份等权 | 每月可等宽／等角；月内位置按该月真实日数分配，说明这是归一化 | 把二月的 50% 与一月的 50% 说成相同天数 |
| 使用环形或重复单位 | 保留完整日期身份，另存周期属性；明确年界与阅读方向 | 将不同年份的一月压成同一个日期；按月份名称字母顺序排列 |
| 按月份或页面分组 | 原日期顺序不变；显式处理跨月周、首尾部分周及邻年日期 | 丢掉第六行日期，或把跨年周标题写成同一个错误年份 |
| 省略或留空 | 区分“不在范围内”“不存在的日期”“缺少内容”三种含义 | 为凑齐视觉矩阵填入不存在的 2 月 30 日；将无记录涂成数值零 |
| 变更视觉语言 | 可独立改变字体、色彩、图像与空白；重新检查实际尺寸可读性 | 换主题图时重新生成日期，导致原有映射和已确认关系变化 |

空间相邻不必等于日期相邻，但有意打断、折行或重新分组时，应给出足够索引。仅靠漂亮的几何形式不能证明时间关系已经保持。

## 两个受控样本，而非两个偏好结论

**等日与等月：**固定同一年的日期、字体和尺寸，只改变月份如何占据空间。等日版本检查总日数、日期顺序及每单位步长；等月版本检查十二个等权区域、各月真实日数及归一化标注。收集用户对整体节奏和日期检索的评价，再决定适用任务。

**连续与分组：**固定日期数据，比较连续周流与月份分区。检查跨月周是否保留、月界是否可找、年份边界是否明确；不预先宣布哪一版“更自然”。

## 每次修改保持的底线

- 无意的漏日、重复日、日期与星期错配不能由视觉风格解释。
- 对数、归一化、删去某些日子的历法等有意变换可以探索，但必须记录变换与相应解释。
- 技术检查证明语义和实现；用户评价检验个人使用感。两种结果单独记录。
