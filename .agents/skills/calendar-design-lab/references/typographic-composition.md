# 排版与构图：从阅读任务到视觉关系

本轮精读后的工作笔记，核对日期：2026-10-29。下面把作者观点与本项目的迁移假设分开；它们不构成用户偏好或设计质量已经成立的证据。

## 实际阅读与来源边界

| 编号 | 阅读位置 | 来源中支持的认识 |
| --- | --- | --- |
| T1 | Massimo Vignelli，[The Vignelli Canon，RIT 官方 PDF](https://www.rit.edu/vignellicenter/sites/rit.edu.vignellicenter/files/documents/The%20Vignelli%20Canon.pdf)：印刷页 48、52 的书籍网格；68、72 的字号关系；80 的布局；84 的序列；92 的留白 | 网格使页面关系与系列延续；留白参与层次、分隔和边缘张力；翻页过程也是阅读。具体的极简立场与字号数量是作者的方法选择。 |
| T2 | Lisa Charlotte Muth，[Datawrapper 数字与字体文章](https://www.datawrapper.de/blog/fonts-for-data-visualization)：数字形式、字形覆盖、字重、字号、对比度及大写章节 | 表格查读受数字高度和宽度形式影响；文章也展示有衬线等表达案例。可读性同时涉及字体、大小、字重与颜色，不能仅给出通用最小字号。 |
| T3 | [Google Design 字体选择指南](https://design.google/library/choosing-web-fonts-beginners-guide)：项目范围、文本量、大小与语言章节 | 字体角色取决于内容和尺寸；短大标题可使用表达性字体；多语言与特殊符号应检查真实字形和组合效果。 |

## 可复用的条件决策

以下是本项目的迁移假设，需通过样本和反馈检验。来源编号说明启发依据，不表示原作者曾规定这些日历规则。

| 条件 | 设计操作 | 需要检验的反例／代价 |
| --- | --- | --- |
| 主要任务是远看查日期 | 先分配日期、月份和辅助文字的阅读角色，再决定其比例与字重。按实际成品尺寸及距离检查。〔T1/T2〕 | 巨大年份可能消耗日号空间；增大所有字不能建立层次。 |
| 主要任务是密集查找 | 可先试等高、等宽数字；它只要求数字宽度一致，不要求整套字体等宽。〔T2〕 | 数字形式不是日历的唯一表达；大幅单日数字可另设展示字体。 |
| 单日数字或月份承担主视觉 | 允许有衬线、比例宽或表达性字形，另设清楚的日期／星期索引。〔T2/T3〕 | 展示字在大尺寸成立，不证明缩成全年小字后仍成立。 |
| 图像与日期并置 | 建立共享锚点、边界与间距关系，检查图像比例与裁切；网格服务材料。〔T1〕 | 对齐只能说明组织有序，不能单独说明构图有吸引力；图像无需填满每个模块。 |
| 留白承担分组、书写或观看停顿 | 为每段空白指定作用，再调节间距和边缘关系。〔T1〕 | 更多空白不自动更高级；书写区域应有实际可用面积。 |
| 月历／日历构成一组连续页面 | 明确日期锚点等不变量，以及图像、比例或节奏等可变量；用相邻页面检查系列感。〔T1〕 | 每页完全一样可能单调；每页全部改变又会提高重新学习的成本。 |
| 输出跨语言、尺寸或字重 | 检查真实文本、数字及符号的字形、宽度与回退；导出后再看一次。〔T2/T3〕 | 字体家族名称相同不能证明所有字形或数字特性都可用；加粗也可能改变占位。 |

数字的高度形式（等高／旧式）与宽度形式（等宽／比例宽）分开记录，并检查所选字体实际支持什么；不要从字体类别推定全部特性。

## 实际选字与构图研究

当字体尚未确定、图文关系缺少依据，或收到明确的用字／排版反馈时，用真实内容做一张轻量研究板，再推进完整设计。已有明确且有效的选字关系时沿用，不强制每次重新比较固定数量的字体。以下是本项目的操作方法，效果仍需通过作品和用户反馈检验。

1. **先分配信息地位。** 列出主要观看对象、查读信息和附注。逐项判断中／英文书名、作者、年份、品牌、编号、周号、每列月份、口号的作用。保留书与整周的完整身份，再做一版删除或降级辅助项的比较；不能用附注填满剩余空位。
2. **比较真实字样，不只列字体名。** 使用本案书名、作者、星期、`04 05 06 07 08 09 10`、实际标点和混排片段。先以相同 em 比较字面率、笔画与数字形态；另做等视觉尺度的调整，标明字号补偿。文件可用、字形齐全和许可明确只是可用条件，选用理由还需对应构图。
3. **检查角色之间的协调。** 比较中文与西文的视觉大小、字重、基线及笔画气质，日期是否显得过重或过轻。七个宽松排列的日号也可使用比例数字；密集对齐才另查等宽特性。按所用字体的实际轴与字形判断，不把手动缩放叫作字体具备光学尺寸，不把“细致选择”自动解释成细字重。
4. **固定内容做构图缩略图。** 保持书目、图像与日期内容，比较主图比例、标题锚点、日期路径和空白用途。先缩小看整体注意力，再按实际输出大小检查字形、间距、标点和光学边缘。检查图像焦点与裁切后关系，网格对齐及文字未越界不能代替构图判断。
5. **留下选择依据。** 记录选中和暂不选用的组合、字重／字号／字距、实际文件与版本、配对理由和待验证点。个人对某版的不满意，不推出禁用某种字体类别、竖排、配色或图像。用户审美判断继续与设计者推理和技术检查分开保存。

研究板可以合并字样、少量构图缩略图和一个关键局部，不要求为每项各造一份文档。确认采用的关系后，再做完整样张并在用户可见消息中展示；不要把改了字体文件或通过越界检查当成设计已经改善的证据。

## 配方中值得保存的关系

按任务保留下列信息，不必把它们预先固化为通用模板枚举：

- 阅读任务、观看距离与成品尺寸。
- 各文字角色的字体版本、数字形式、实际字号／比例、字重和对齐规则。
- 日期单元、图像和注释的锚点与间距；哪些空白用于分组、书写或视觉停顿。
- 系列中的固定关系、允许改变的项目，以及所选页面／素材快照。

检查串可以包括 `01 11 28 31` 和该作品的真实月份、星期及用户文字。先发现缺字、宽度或拥挤问题，再判断是否需要改变字体、字号、结构或内容。

## 用于下一组样本的对照方式

固定时间结构时，一次只改变数字角色、层次比例或留白关系，观察差别。若同时更换构图、字体、色彩和图像，应标为整套创作方向，不能把评价归因于单个变量。

这些原则不指定默认色板、通用字体或固定字号数量；审美认可由用户评价，技术检查另行记录。
