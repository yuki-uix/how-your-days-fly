# 可复用设计语言：决策、关系与验证

按年／月／周／日把结构、规则、样本与素材一起查看，使用[统一设计总览](../../../../docs/design-atlas.md)。本页负责设计判断与规则 ID；原始样本设计卡继续保留实际使用记录。

这是精读公开资料后形成的项目工作方法。文献依据见[时间语义](temporal-semantics.md)和[排版与构图](typographic-composition.md)。它们支持设计推理，不预先决定某个人会喜欢什么，也不规定统一风格。

## 先写设计卡，再选择外观

| 层 | 必须明确的决定 | 例子 |
| --- | --- | --- |
| 使用任务 | 什么最先被看见、在哪里使用 | 隔一段距离查日期、看全年跨度、近距离书写、每天翻开一页 |
| 时间语义 | 展示范围、单元、映射、边界 | 展示一年、以民用日期为单位、等日步长；月份归一化另作标注 |
| 空间组织 | 分组、路径、方向与索引 | 连续周跨月，或十二月分面；月界、邻年日期可定位 |
| 阅读角色 | 展示文字、查读数字、索引、附注 | 大幅日期可用比例宽字体；密集日期可用等宽数字 |
| 构图关系 | 锚点、比例、节奏和空白用途 | 图像与月格共用边缘，空白服务书写或分组 |
| 系列关系 | 哪些固定，哪些允许变化 | 日期索引与基线固定，图像或主数字随页面变化 |
| 验证方式 | 什么由代码检查，什么由用户评价 | 日期覆盖、角度含义、字体与越界；是否愿意使用另记 |

这些是开放问题，不是强制每份日历回答同一问卷。已有明确 brief 时沿用它；未知偏好通过可比较的视觉作品探索。

## 操作顺序

1. 从资料里摘出少量事实与适用条件，保持作者语境。把自己的迁移方法标为假设。
2. 选择阅读任务，声明时间模型，再选择空间形式；不要先画一个漂亮形状再填入日期。
3. 给文字分配角色，检查选定字体真实的数字宽度、字形和版本。不同角色可以使用不同表达，但需要清楚的关系。
4. 用网格保持锚点和序列，用比例与空白建立注意力。网格对齐本身不证明作品有吸引力。
5. 设计探索可以同时变化多项，但应称为整体创作方向。检验某项原则时，固定其余因素，明确改变的一项。
6. 保存源数据、设计卡、实现、字体/素材及快照。变更年份或内容时先检查不变量，再评价新的视觉结果。

字体或构图尚未建立依据、或受到相关反馈时，执行[实际选字与构图研究](typographic-composition.md)：用真实内容比较字样与角色搭配，先做信息减法和构图缩略图，再完成样张。字体覆盖、对齐和无溢出分别是技术事实，不能替代选择理由与整页观看效果。

## 修改时怎样定位问题

| 反馈／现象 | 优先检查 | 不要直接推断 |
| --- | --- | --- |
| 看不出时间在往前走 | 分组是否切断顺序、月界索引、阅读方向 | 必须改为连续周或减少所有空白 |
| 查日期费劲 | 数字角色、密度、星期/月的入口、实际阅读尺寸 | 用户不喜欢有衬线字体 |
| 画面无聊或像默认模板 | 是否有明确的主关系、比例与材料选择是否服务任务 | 换一张背景图或换一种颜色就足够 |
| 图片和日期像拼在一起 | 共用锚点、间距、图像占比、裁切与文字入口 | 所有图像必须铺满或所有月格必须居中 |
| 书写区域不舒服 | 每日实际面积、边界和留白用途 | 日历必须具有工作效率工具的样子 |

## 本轮六份样本怎样使用这些原则

- J1：横向连续周年历，保留日期相邻与月界索引，展示年份与查读数字分工。
- J2/J3：同一套字体、色彩、半径、起点与标签规则，仅改变等日／等月映射，并分别说明含义。
- J4：原创光影图像与完整月格共享边缘；图像、月份展示字与日期有不同阅读角色。
- J5：横向周页以真实书写空间为主体，七天采用一致的基线与面积。
- J6：单日比例宽字形承担主视觉，完整日期、星期及相邻日索引提供定位。

J1/J4/J5/J6 是整体方向研究，不能把喜好变化归因于某一个变量。J2/J3 是受控映射比较。所有字体与配色都是探索选择，尚非用户偏好结论。

样本设计卡使用下列可扩展的规则 ID，便于回溯，不将它们作为封闭的模板枚举：

| ID | 操作与依据 |
| --- | --- |
| `temporal:continuous-order` | 保留跨月顺序与索引；见时间语义的分组规则 |
| `temporal:declared-normalization` | 分别声明等日或等月，检查被保留的关系；见时间语义的归一化规则 |
| `type:display-versus-lookup` | 展示字与查读数字分配不同角色；见排版与构图 |
| `type:shared-anchors` / `type:image-date-anchors` | 保留共用边缘和间距关系；见排版与构图的图像、网格条件 |
| `type:nested-hierarchy` | 将年份、月份索引与日号分层检查；见排版与构图的阅读角色 |
| `type:purposeful-whitespace` | 空白对应实际书写或分组任务；见排版与构图的留白条件 |
| `type:series-invariants` | 记录页间锚点与可变量，系列效果另行验证 |
| `type:expressive-display-numerals` | 大幅字形可探索比例宽，保留完整日期索引；见排版与构图的展示字条件 |

## 资产和输出的具体要求

- 字体使用可核实许可的文件，保留许可证、版本/哈希和来源；不要只记录家族名称。
- 记录生成图像的完整提示词、工具模式、所选文件及哈希。生成图像的来源记录不等于版权或独占性保证。
- 研究参考图与可分发资产分开管理。原书插图不因被阅读而成为模板资产。
- 屏幕校样的字形需要稳定时可输出字形轮廓，同时保留可再编辑的文字、字体和布局源；不要把轮廓文件当成唯一源。
- 当前新样本只检查所用英文文字、数字与符号；不能据此宣称中文或所有语言的排版能力已经验证。

## 证据边界

“资料已读”“方法已写入 skill”“代码通过”“输出已目视检查”“用户愿意使用”分别记录。前四项不能自动升级为第五项。首次跨年份重放和跨用户体验也各自验证。
