# 拉丁字形研究用源资产

核对日期：2026-10-30。这里保留六个候选家族、八份**未经修改的原始可变 TTF**，以及六份各自的原始 OFL。总大小 4,860,629 bytes（含许可，不含本说明与清单），用于英文字体和日历角色的字样研究；不是已获用户认可的选字列表。

全部来自 Google Fonts 官方仓库的固定提交 `6157dfaa640ca5738b4d1a7070fe389c3036d7fc`。每份原始文件的不可变下载 URL、Git blob、SHA-256 和字节数见 [manifest.json](manifest.json)；原始字体名称和字节均未修改。来源的完整授权仍以各家族随附 `OFL.txt` 为准。

## 授权与工作副本

六个目录都随附 OFL 1.1 原文。Source Sans 3 的原 OFL 头明确声明保留名称 `Source`；另外五份的许可头未声明保留名称。许可正文仍有适用条件，包括与字体再分发、修改、版权说明和名称有关的要求；不能把 OFL 字体改以项目自己的许可发布，也不能单独出售字体。

原始字体与许可应始终保留。若将可变字体实例化为静态字体、转换格式或子集化，为派生文件保存修改说明、参数、版本和哈希；重新读取对应 OFL 的名称规定。项目静态工作副本采用不同主名称，不代表设计了新字体。这里没有保存或发布派生字体。

## 实测范围

FontTools 4.68.0 在内存中将每份文件设为 `wght=400`，其余轴设为**该原始文件的默认值**，测量默认 cmap 字形、hmtx advance、H／h／x／数字／易混字符的墨迹框；并记录 GSUB 与 GPOS feature 标签。所有测量值与文件路径一一对应，见清单的 `per_file`。

通用试样：`January September Wednesday Books & Days 2027 01 08 11 28 31 Il1 O0 ‘ ’ “ ” – — é É`。八份文件均无此试样缺字；这不构成完整英语排版、全部拉丁语种、所有变音符或 Unicode 组合序列的覆盖认证。

| Roman，400／其余轴默认值 | UPM | 默认数字 advance | 可据此判断 |
| --- | --- | --- | --- |
| Source Serif 4，opsz=20 | 1000 | 0–9 都为 500 | 此实例默认数字等宽 |
| Newsreader，opsz=18 | 2000 | 0–9 都为 1100 | 此 Roman 实例默认数字等宽 |
| Bodoni Moda，opsz=11 | 2000 | 869–1239 | 此实例默认数字比例宽 |
| Source Sans 3 | 1000 | 0–9 都为 497 | 此实例默认数字等宽 |
| Inter，opsz=14 | 2048 | 833–1323 | 此实例默认数字比例宽 |
| Space Grotesk | 1000 | 418–641 | 此实例默认数字比例宽 |

原生 Italic 单独测量：Source Serif 4 400/20 的数字均为 511/1000 em；Newsreader 400/18 的 `7` 为 1300/2000 em，其余数字为 1100/2000 em。**不能从同家族 Roman 推定 Italic 的默认数字也等宽**。

跨字体比较要先除以各自 UPM。等宽／比例宽与等高／旧式是不同维度；相同 advance 不证明数字高度类别，也不证明墨迹相似或查读更快。`Il1`、`O0` 的 advance 和墨迹框只支持实际字样研究，不能用这些数值直接认证可辨识性。

本测量**没有执行 GSUB/GPOS**，不启用 kerning、连字、数字替代、语言选择或样式集。发现 `tnum`、`pnum`、`onum` 或 `lnum` 不表示渲染结果已应用它。当前项目逐码点轮廓路径也不自动执行这些功能。新源文件支持某一轴或功能，不等于现有导出器已经实现。

下一步研究若选择不同 `opsz`、字重、原生斜体或排版环境，应在配方中记录实际轴值，并重新检查字形、数字、间距与输出。相同 nominal 字号、相同墨迹高度和相同感知大小不互相等同。

## 重新获取与校验

原始文件可使用清单中固定提交的 `local_files[].source` 重新下载，再比对 SHA-256 和 Git blob。`fetch_measure_fonts.py` 是本轮使用的获取与测量脚本；默认固定上述提交，依赖 FontTools 4.68.0 与 curl，不会导入系统字体。生成过程中的静态实例只存在于内存中。

字体选择方法与原设计者的语境应和本页的文件事实分别阅读；这些素材不预设整套日历必须采用某种西文风格。
